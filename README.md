# Observation_TMS4
Skill for TMS4 csv data

## 관측

- 지점: 노르웨이 스발바르(2026년 7~8월), 보성(9~10월) 등. 지점마다 짧은 센서(S)와 긴 센서(L)를 설치한다.
- 장비: TOMST TMS4 (유전율 기반 토양수분, 온도 T1·T2·T3), 다운로드 프로그램 Lolly
- 현장 기록지(xlsx): 지점별 센서 배치와 설치 높이·깊이, 다운로드 방문 시각, 동물 훼손(소변, 파헤침), 흙 채움, 센서 이설·철거 같은 현장 사건을 적는다.

## 자료 받기

- 파일 이름: 지점_센서_날짜.csv (예: B2_S11_20260807.csv)
- 형식: 세미콜론 구분, 열 순서는 순번, 시각, T1, T2, T3, 수분 원시값, 체적함수율(%), 오류 플래그. 15분 간격.
- 시각: TMS 파일은 UTC, 현장 기록지는 현지시각(스발바르 여름 UTC+2).
- 값: Lolly에서 체적함수율(%)로 변환된 값을 내려받는다.
- 기기 메모리를 지우지 않으므로 다운로드마다 이전 자료가 겹친다.

## 받은 뒤 점검하는 것

- 연속성: 15분 간격이 끊기지 않았는지, 중복이나 빈 기록이 없는지 확인한다.
- 접촉 이상: 유전율 센서는 동물이나 사람이 건드리면 센서와 흙 사이 공극이 커져 값이 갑자기 떨어진다. 흙을 채우는 등 재정비하면 급히 회복된다. 강수에 의한 증가와 구분한다.
- 기록지 대조: 기록지에서 TMS, mushroom, S##, L##이 들어간 항목만 읽어 다운로드 시각과 현장 사건을 자료와 맞춰 본다.
- 이설: 센서를 다른 지점으로 옮기면 이전과 이후를 지점별 파일로 나눠 저장한다.

## 플래그

- 0: 정상
- 1: 다운로드하는 동안의 자료
- 3: 외력 접촉으로 값이 작아졌다가 복구한 구간 (보정값 사용)
- 4: 외력 접촉으로 값이 작아진 뒤 회복이 없는 구간
- 8: 튀는 스파이크 값
- 9: 결측 (NaN)
